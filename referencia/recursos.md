# 🌐 Fontes e recursos

Curadoria do que vale o seu tempo — e **para quê** cada um serve. As fontes oficiais vêm primeiro: quando um tutorial e o manual discordarem, o manual vence.

## Oficiais (projeto Git)

| Recurso | Melhor para |
|---|---|
| [Documentação de referência](https://git-scm.com/docs) | o manual de cada comando (o mesmo do `git help`) |
| [Pro Git, 2ª edição — em português](https://git-scm.com/book/pt-br/v2) | o livro de referência, gratuito (Scott Chacon e Ben Straub, licença CC BY-NC-SA 3.0) |
| [Cheat sheet do projeto](https://git-scm.com/cheat-sheet) | resumo visual dos comandos essenciais |
| [Downloads](https://git-scm.com/downloads) | instaladores oficiais |
| [Mudanças planejadas para o Git 3.0](https://git-scm.com/docs/BreakingChanges) | o que muda (branch `main`, SHA-256, reftable) |
| [Notas de versão](https://github.com/git/git/tree/master/Documentation/RelNotes) | o que entrou em cada versão |
| [Código-fonte (espelho no GitHub)](https://github.com/git/git) | ler como o Git funciona por dentro |

## Documentação das plataformas (cursos irmãos desta trilha)

| Recurso | Melhor para |
|---|---|
| [GitHub Docs — Começar com Git](https://docs.github.com/pt/get-started/git-basics) | Git do ponto de vista do GitHub |

| [Atlassian — Git tutorials](https://www.atlassian.com/git/tutorials) | tutoriais visuais (fluxos de trabalho, merge × rebase), do time do Bitbucket |

## Fluxos de trabalho

| Recurso | Melhor para |
|---|---|
| [GitHub flow](https://docs.github.com/pt/get-started/using-github/github-flow) | fluxo simples com branch curta + PR |

## Ferramentas

| Ferramenta | Para quê |
|---|---|
| [git-filter-repo](https://github.com/newren/git-filter-repo) | reescrever histórico (remover arquivos/segredos) — recomendado pela documentação do Git no lugar de `filter-branch` |
| [Gitleaks](https://github.com/gitleaks/gitleaks) | encontrar segredos no histórico |
| [pre-commit](https://pre-commit.com/) | gerenciar hooks de qualidade |
| [Git LFS](https://git-lfs.com/) | arquivos binários grandes |
| [tig](https://jonas.github.io/tig/) · [lazygit](https://github.com/jesseduffield/lazygit) | interfaces de terminal para o Git |
| [Git Credential Manager](https://github.com/git-ecosystem/git-credential-manager) | login seguro nas plataformas |
